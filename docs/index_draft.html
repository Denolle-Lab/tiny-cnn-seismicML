Labels

No window was picked by hand. Each class comes from a rule that can be rerun, and the review site lets people check the rule against their own eyes. These rules are weak labels: they are right most of the time, and the held-out results below show one window where a rule was probably wrong.

ClassRuleParameters
EarthquakeCatalog event within 150 km, window cut around the ComCat P pick (comcat:p_pick)M 3.0–7.0, 2020-01-01 to 2025-12-01, 30 s before P to 90 s after (120 s). Up to 10 stations per event. 98 windows dropped after manual review (docs/ak_dropped_windows.csv).

TrafficTime of day at an urban school Shake (timeofday)07–19 AKDT = Traffic, 01–05 AKDT = Noise, other hours dropped. A night window with a raw peak ≥20× the station's median night RMS is a single vehicle pass and becomes Traffic. Windows within 120 s of a USGS M≥2 event within 2° are dropped.

Training data

All models share one pipeline, in notebooks/03_training/train_cnn_multiclass.ipynb. In order:

  1. Preprocess. Merge, linear detrend, demean, 4-corner Butterworth band-pass 2–20 Hz (2–45 Hz for the aircraft set), resample to 100 Hz. Windows with data gaps are dropped. Amplitudes stay in filtered counts.
  2. Crop to 60 s. Every model input is 6,000 samples. Continuous windows are already 60 s. Each 120 s earthquake window gives two crops: one that starts before the P arrival and one from anywhere in the window, so the model sees onsets and coda.
  3. Normalize. Each crop is z-scored on its own (subtract mean, divide by standard deviation). The models never see absolute amplitude, so a loud site and a quiet site look alike; this is also why a new sensor's noise can be mistaken for a signal.
  4. Balance. K222 alone has 8,848 quiet windows. Later runs cap Noise per station (seed 42) so no single site stands for the class. Positive classes are never capped.
  5. Pick classes. Windows of classes the model does not learn are dropped and the rest are remapped to 0…K−1.
  6. Split. Stratified 80 / 10 / 10 train / validation / test with random_state=42. The split is by crop, not by station or day, so test windows share stations and days with training windows. The held-out set below removes that overlap.
  7. Train. Adam, learning rate 5×10⁻⁴ (compact) or 4×10⁻⁴ (standard), weight decay 10⁻³, batch 32, gradient clipping at 2.0, class-weighted cross-entropy, ReduceLROnPlateau on validation loss, data augmentation on, up to 60 epochs with early stopping after 10 epochs without a 0.001 drop in validation loss.

The saved weights are from the last epoch, not the epoch with the lowest validation loss. The notebook keeps a shallow copy of the best state (state_dict().copy()), which the optimizer keeps overwriting. The training curves mark both epochs. A fix (copy.deepcopy) will apply to future runs.

Models

Each training run fits two architectures on the same data. Compact has three convolution blocks and about 9,300 parameters; standard has four convolution blocks and two dense layers, about 94,000 parameters. Test metrics use the 10% test split of each run.

Deployment

A deployable model is a folder models/<id>/ with two files, read by the CLUE WaveRunner tile in the browser:

{
  "$schema": "https://collaborative-learning.concord.org/schemas/seismic-model/v1.json",
  "id": "compact-v6",
  "architecture": "compact",
  "class_names": ["Noise", "Traffic"],
  "sampling_rate": 100,
  "window_duration": 60,
  "instrument_types": ["B", "E", "H"],
  "weightsUrl": "./weights.json",
  "test_accuracy": 0.9596
}

weights.json holds the trained weights in TensorFlow.js layout, exported from the PyTorch checkpoint with scripts/export_compact_weights_for_tfjs.py or export_standard_weights_for_tfjs.py. Steps are in docs/generating-model-weights.md.

To get sensible output, give a model what it was trained on:

  • one vertical component, 60 s at 100 Hz (6,000 samples);
  • band-passed 2–20 Hz, then z-scored over the window;
  • a sensor like the training ones: instrument_types lists SEED band codes, B = broadband (BHZ), E = short-period geophone (EHZ), H = high-rate accelerometer (HNZ). compact-v4 and standard-v3 still list ["H", "N"] from an earlier convention.

Output is a softmax over class_names, in that order. A model always picks one of its own classes, so a two-class Noise/Traffic model will call an earthquake Noise or Traffic.

Held-out inference

The test splits above share stations and days with training. To see how the models do on data they have never touched, we collected new days at the same stations and drew 10 windows per class (seed 42): Romig on 2026-09-11, Turnagain on 2026-09-14, K222 on 2026-05-11 to 05-14 and 09-14, and 14 earthquakes (M3.0–3.9, 2026-08-14 to 09-24) at FIRE, RC01 and SSN. The same labeling rules were applied. Earthquake crops start 10 s before P.

Only 2 Train windows exist: 2026-09-14 was the last passenger day at K222, and on the four unused days before the season (05-11 to 05-14) only one scheduled passage reached the 3× detection threshold. Treat the Train results as anecdotes.

What the table shows:

  • New sites break the three-class models. compact-v3 and standard-v2 trained only on the AK broadbands and Romig. Quiet windows from Turnagain and K222 (#6–8) come out as Earthquake with confidence up to 1.00 (compact-v3) or as Traffic (standard-v2). Models trained on Noise from every site mostly get them right; compact-v4 still calls the two Turnagain quiet windows Aircraft, at 0.51 and 0.59.
  • Window #4 is probably mislabeled. It is a 02:41 night window at R3130 with 2.5× the band RMS of the other night windows; five models call it Traffic at 0.94–0.99. It likely holds a vehicle pass below the 20× burst threshold.
  • Earthquakes are easy for every model that knows them (10/10 each), which matches the near-perfect test scores.
  • Out-of-scope rows show what a model does with a signal it was never taught. compact-v5 and standard-v4 call every traffic, train and aircraft window Noise, which is the safe answer. compact-v3 calls all 10 aircraft windows Earthquake and standard-v2 calls them all Traffic. The Noise/Traffic models call 4 (compact-v6) and 2 (standard-v5) of the 10 earthquakes Traffic.
