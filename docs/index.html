How the data are made

Continuous data are pulled after the fact from the public FDSN archives (Raspberry Shake for the AM network, IRIS for AK), cut into non-overlapping 60 s windows at 100 Hz, band-passed 2 to 20 Hz, and labeled by rules: time of day, night bursts, timetable search, and catalog exclusion of earthquakes. One command per class regenerates the sets on any machine; waveform files are never published, only plots and metadata.
